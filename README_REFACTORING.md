# Сапер — перероблена ООП-версія

## Що змінено

- Додано нормальну точку входу в `main.py`: гра запускається тільки через `if __name__ == "__main__"`.
- При імпорті модулів більше не створюються вікна і не запускається `mainloop()`.
- Прибрано `from menu import *`.
- Налаштування більше не передаються списком за індексами. Тепер використовується `GameSettings` із зрозумілими полями: `rows`, `cols`, `difficulty`, `cell_size`, `timer` тощо.
- Прибрано перезапуск програми через `os.execl(...)`. Повернення в меню виконується через методи класу `MinesweeperApp`.
- Глобальні змінні замінено полями класів.
- Код розділено на файли за відповідальністю.
- Текст інтерфейсу та коментарі перекладено українською.

## Структура

```text
main.py              # точка входу
app.py               # головний клас застосунку
models.py            # dataclass GameSettings і стандартні пресети
storage.py           # читання/запис налаштувань, пресетів і рекордів
audio_manager.py     # музика та звукові ефекти
widgets.py           # спільні віджети: кнопка, помилка, GIF
game_board.py        # модель поля: міни, відкриті клітинки, прапорці
game_window.py       # ігровий екран і механіка взаємодії
menu_windows.py      # головне меню, меню налаштувань, рекорди
sounds/              # аудіо та gif
settings.json        # налаштування у форматі словника з ключами
presets.json         # пресети
records.json         # рекорди
```

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Головна архітектурна ідея

`MinesweeperApp` керує всіма переходами:

```text
головне меню → меню налаштувань гри → гра → головне меню / нова гра
```

Тепер закриття гри або вікна поразки/перемоги не перезапускає весь Python-процес, а просто перемикає екран усередині вже запущеної програми.
